# QEB Public Media

Public distribution repository for approved Questionable Evidence Bureau
social-media assets.

## Publication boundary

ONLY assets that have completed the QEB publication gate and are explicitly:

APPROVED / READY TO PUBLISH

may be committed here.

DO NOT STORE:
- drafts
- review renders
- superseded artwork
- source artwork
- character references
- private notes
- credentials or tokens
- renderer source code
- internal case-development files

Content placed in this repository must be treated as publicly accessible.
